# PWA 적용 기록

내 차 수첩을 폰에 설치해서 앱처럼 쓸 수 있도록 PWA(Progressive Web App)로 만든 과정과 이유를 정리한다.

- 작업일: 2026-11-10
- 배포 주소: https://car-notebook-mu.vercel.app

## 1. 왜 PWA인가

폰에서 주로 쓰는 앱이라 "앱처럼" 동작해야 했다. 방법은 세 가지를 비교했다.

| 방법 | 장점 | 단점 | 결정 |
|---|---|---|---|
| PWA | 지금 웹 코드를 그대로 쓴다. 무료. 배포하면 바로 반영된다 | 네이티브 앱보다 기기 기능 접근이 적다 | **채택** |
| Capacitor로 감싸서 스토어 출시 | 같은 코드로 Play 스토어, App Store 출시 가능 | 등록비, 스토어 심사, 아이폰은 보통 Mac 필요 | 나중에 출시할 때 검토 |
| React Native로 새로 개발 | 가장 자연스러운 네이티브 앱 | 화면과 3D를 거의 다시 만들어야 한다 | 보류 |

결정 이유

1. 희망 직무가 웹 프론트엔드라 웹 코드를 살리는 편이 포트폴리오에 맞다.
2. 아직 기능을 자주 고치는 단계라, 올리면 바로 반영되는 웹 배포가 편하다. 스토어 앱은 수정할 때마다 심사를 기다려야 한다.
3. 나중에 스토어에 내고 싶으면 Capacitor로 지금 코드를 감싸면 된다. PWA 작업이 버려지지 않는다.

## 2. 무엇이 바뀌었나

| 항목 | 전 | 후 |
|---|---|---|
| 홈 화면에 추가 | 브라우저 바로가기. 주소창이 보인다 | 앱 아이콘으로 설치. 주소창 없이 전체 화면으로 열린다 |
| 앱 아이콘 | 없음 (사이트 캡처) | 보라·핑크 그라데이션 계기판 로고 |
| 인터넷 없을 때 | 화면이 안 열린다 | 앱 화면이 열리고, 로그인 전 기록은 보고 입력할 수 있다 |
| 두 번째 실행부터 | 매번 내려받는다 | 저장해 둔 파일로 바로 열린다 |
| 아이폰 노치, 홈 바 | 고려 안 함 | 안전 영역을 피해서 배치한다 |

## 3. 바뀐 파일

| 파일 | 내용 |
|---|---|
| `vite.config.js` | `vite-plugin-pwa` 설정 (manifest, 서비스 워커, 캐시 규칙). `base`를 `'./'`에서 `'/'`로 변경 |
| `index.html` | `viewport-fit=cover`, 아이콘 링크, iOS 설치용 메타 태그 |
| `public/icons/` | 앱 아이콘 5개 (아래 표) |
| `src/styles.css` | 탭 번쩍임 제거, 두 번 탭 확대 방지, 화면 끝 튕김 방지 |
| `src/components/layout/AppShell.jsx` | 상단 바가 아이폰 상태바 영역을 피하도록 위쪽 안전 영역 여백 추가 |
| `package.json` | `vite-plugin-pwa` 추가 (개발용) |

### 앱 아이콘

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `icon.svg` | 벡터 | 브라우저 탭 아이콘(파비콘) |
| `icon-192.png` | 192×192 | 안드로이드 홈 화면 |
| `icon-512.png` | 512×512 | 안드로이드 시작 화면, 설치 창 |
| `icon-maskable-512.png` | 512×512 | 안드로이드가 원·물방울 모양으로 잘라 쓰는 아이콘. 잘려도 로고가 남도록 로고를 가운데 60% 안에 둔다 |
| `apple-touch-icon.png` | 180×180 | 아이폰 홈 화면. 아이폰이 직접 모서리를 둥글게 깎으므로 꽉 찬 사각형으로 만든다 |

## 4. 어떻게 동작하나

### manifest (앱 정보)

빌드하면 `dist/manifest.webmanifest`가 생기고 `index.html`에 자동으로 연결된다. 주요 값:

| 값 | 설정 | 의미 |
|---|---|---|
| `display` | `standalone` | 주소창 없이 앱처럼 연다 |
| `start_url`, `scope` | `/` | 아이콘을 누르면 홈에서 시작하고, 사이트 전체가 앱 범위다 |
| `orientation` | `portrait` | 세로 화면으로 고정한다 |
| `theme_color`, `background_color` | `#f4f2fc` | 상태바 색과 시작 화면 배경 (라이트 테마 바탕색) |

### 서비스 워커 (오프라인, 빠른 실행)

`vite-plugin-pwa`가 Workbox로 `dist/sw.js`를 만든다. 사용자가 처음 접속하면 브라우저가 서비스 워커를 설치하고 아래 규칙으로 파일을 저장한다.

| 대상 | 규칙 | 이유 |
|---|---|---|
| 앱 파일 (JS, CSS, HTML, 아이콘) | 설치할 때 미리 저장 (precache) | 인터넷 없이도 앱 화면이 열린다 |
| 폰트 (Pretendard, IBM Plex) | 처음 받을 때 저장하고 1년 동안 재사용 (CacheFirst) | 폰트는 거의 안 바뀐다 |
| Supabase (로그인, 기록) | **저장하지 않음** | 항상 서버의 최신 기록을 받아야 한다. 오래된 기록을 보여 주면 안 된다 |

처음 설치할 때 약 2MB를 내려받는다. 그중 약 0.9MB가 3D 차 코드라서, 3D는 홈에서 필요할 때 따로 불러오도록 나눠 두었다.

### 업데이트

`registerType: 'autoUpdate'`로 설정했다.

1. GitHub `main`에 올리면 Vercel이 새 버전을 배포한다.
2. 사용자가 앱을 열면 서비스 워커가 새 버전을 확인하고 백그라운드에서 받는다.
3. 다음에 앱을 열 때 새 버전으로 바뀐다. 사용자가 할 일은 없다.

`cleanupOutdatedCaches`로 예전 버전 파일은 자동으로 지운다.

### 앱다운 터치 동작 (`src/styles.css`)

| 설정 | 효과 |
|---|---|
| `-webkit-tap-highlight-color: transparent` | 버튼을 누를 때 생기는 회색 번쩍임을 없앤다 |
| `touch-action: manipulation` | 두 번 탭해서 확대되는 것을 막는다. 두 손가락 확대는 접근성을 위해 그대로 둔다 |
| `overscroll-behavior-y: none` | 화면 끝에서 당겼을 때 튕기거나 새로고침되지 않게 한다 |

### 안전 영역

`viewport-fit=cover`로 화면 전체를 쓰고, 아래 요소에서 `env(safe-area-inset-*)`만큼 비켜 둔다.

- 상단 바: 위쪽 (상태바, 노치)
- 하단 탭: 아래쪽 (홈 바)
- 페이지 좌우 여백: 왼쪽, 오른쪽 (가로 화면)

## 5. 설치 방법

### 아이폰 (Safari)

1. Safari로 배포 주소를 연다. iOS 16.4 이상은 크롬에서도 된다.
2. 아래쪽 공유 버튼을 누른다.
3. **홈 화면에 추가**를 누른다.

### 안드로이드 (크롬)

1. 크롬으로 배포 주소를 연다.
2. 주소창 옆이나 메뉴(점 세 개)의 **앱 설치** 또는 **홈 화면에 추가**를 누른다.

## 6. 데이터 저장과 주의점

- 로그인 전 기록은 기기 안(localStorage)에 저장된다. 인터넷 없이도 보고 입력할 수 있다.
- 로그인한 기록은 Supabase에 저장된다. 인터넷이 없으면 불러오기와 저장이 안 되고 오류 안내가 뜬다.
- **아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로다.** Safari에서 로그인 없이 넣은 기록은 설치한 앱에서 안 보인다. 로그인해서 쓰면 둘 다 같은 서버 기록을 본다.
- 앱을 지우거나 브라우저 데이터를 지우면 로그인 전 기록은 사라진다. 백업 메뉴로 JSON을 받아 두거나 로그인해서 쓴다.

## 7. 확인한 것

| 항목 | 방법 | 결과 |
|---|---|---|
| 빌드 | `npx vite build` | `manifest.webmanifest`, `sw.js` 생성, 미리 저장 파일 목록에 앱 파일과 아이콘 포함 |
| manifest | 빌드 결과 확인 | 이름, 아이콘 3개, `standalone` 정상. 한글 UTF-8 정상 |
| 서비스 워커 등록 | 크롬에서 `vite preview`(localhost:4173) 접속 | `activated`, 페이지가 서비스 워커의 관리를 받음, 파일 11개 저장 |
| 오프라인 | 미리보기 서버를 끄고 새로고침 | 홈 화면, 하단 탭, 계기판, 3D 차가 그대로 열림 |

확인하지 못한 것

- 실제 아이폰, 안드로이드에서 설치와 전체 화면 실행
- 노치가 있는 아이폰에서 안전 영역 배치
- Claude 데스크톱 앱 안의 브라우저 패널은 서비스 워커를 지원하지 않아서, 그 화면에서는 오프라인 기능을 확인할 수 없다 (일반 크롬에서 확인)

## 8. 직접 확인하는 방법

개발 서버(`npm run dev`)에서는 서비스 워커가 동작하지 않는다. 빌드한 결과로 확인한다.

```bash
npm run build
npx vite preview
```

크롬에서 http://localhost:4173 을 열고 개발자 도구 → Application 탭에서:

- **Manifest:** 이름, 아이콘, 설치 가능 여부
- **Service workers:** `activated and is running`
- **Cache storage:** `workbox-precache-...` 안의 파일 목록
- **Network → Offline** 체크 후 새로고침해서 오프라인 실행 확인

확인이 끝나면 Application → Storage → **Clear site data**로 localhost의 서비스 워커를 지워 둔다. 남아 있으면 다음 미리보기에서 예전 화면이 보일 수 있다.

## 9. 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 배포했는데 폰에 예전 화면이 나온다 | 서비스 워커가 다음 실행 때 바꾼다. 앱을 완전히 닫았다가 다시 연다 |
| 아이콘이 예전 것으로 남는다 | 홈 화면 아이콘을 지우고 다시 설치한다. 아이폰은 아이콘을 오래 저장해 둔다 |
| 로그인 기록이 안 보인다 | 인터넷 연결을 확인한다. Supabase 요청은 저장해 두지 않는다 |
| 설치 버튼이 안 보인다 (안드로이드) | HTTPS 주소인지, 개발자 도구 Manifest 탭에 오류가 없는지 확인한다 |
